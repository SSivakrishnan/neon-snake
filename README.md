# Neon Snake

A browser snake game with solo play and local two-player battles. No accounts, installation, or backend required.

## Play

- Player 1: WASD
- Player 2: arrow keys
- Space: pause or resume
- R: restart

Choose Solo Run for single-player mode. Multiplayer uses one shared keyboard; online multiplayer is not included.

Open index.html directly, or serve this directory with any static web server. GitHub Pages publishes the main branch root.
